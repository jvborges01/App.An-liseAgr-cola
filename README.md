# 📊 EstimatedNir

O **EstimatedNir** é um projeto focado em cálculo, estimativa ou análise de dados (NIR - Near Infrared ou métricas relacionadas, dependendo do contexto do projeto).  
A aplicação tem como objetivo fornecer uma forma estruturada de processar, analisar ou estimar valores com base em entradas específicas.

## Como Executar

- Crie o ambiente: O comando abaixo cria uma pasta chamada venv com os arquivos do ambiente.
bash

      python -m venv venv

- (Opcional: Você pode alterar o segundo "venv" para outro nome).
Ative o ambiente:

      Windows: venv\Scripts\activate
      Linux/macOS: source venv/bin/activate
  O prompt do terminal mostrará (venv) indicando que está ativo.

- Instale as Depedências :

        python -m pip install --upgrade pip wheel setuptools
        pip install -r requirements.txt
        pip install pyinstaller

- Para Executar:
  
        python main.py
